===== Merchant =====

Many different merchant types may visit by river boat, covering all item categories:

^ Merchant ^ Offers ^
| General | All good categories, crop and orchard seeds, and livestock |
| Organics | Fruit and vegetables |
| Grain | Grain |
| Protein | Protein (meat) |
| Textiles | Textiles and fabric |
| Resources | Wood, stone, iron, fuel, tools, herbs, and industrial fuel |
| Seeds | Crop and orchard seeds |
| Livestock | Livestock |
| Clothing | Clothing |
| Alcohol | Alcohol |
| Minerals | Coal |
| Crafted | Crafted goods |
| Forged | Forged / metalwork goods |
| Materials | Raw materials |
| Construction | Building supplies |
| Precious | Precious goods |
| Misc | Miscellaneous goods |

All merchants accept any settlement goods as payment.
